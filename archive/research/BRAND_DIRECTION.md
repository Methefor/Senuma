# Brand direction (for decision — nothing here is chosen)

“Browser OS” is a working codename and the store listing is still “New Tab Folders”. This
document prepares the naming decision; it does not make it. No domain was bought, nothing was
renamed. Research date: 2026-10-02. All searches are **preliminary**: a store search and a
registry lookup are not a trademark clearance.

## What the name has to do

1. Say “a place you start from”, not “a folder of bookmarks”.
2. Work in English and Turkish: easy to say, no awkward meaning.
3. Short: two syllables ideally, three at most.
4. Not promise what the product is not: no “AI”, “OS”, “sync”, “cloud”.
5. Not lean on someone else's mark (“Chrome”, “Arc”, “Notion”, “Raycast”…).
6. Be findable: the store subtitle keeps “new tab”.

Dropped from the five: **Kiln** (meaning does not carry, hard to pronounce in Turkish, two
software marks) and **Liftoff** (tone).

### Which travel best

1. **Mesa** and **Daybase** are the easiest to say and remember across languages.
2. **Sahne** is the most distinctive and the most local.
3. **Tessera** and **Vantage** work in English and Europe, less well in Turkish.

### What still has to happen before any of these is safe

- A proper trademark search (USPTO, EUIPO, TÜRKPATENT) in the software classes.
- A decision on the domain pattern, since no bare `.com` is free (`get…`, `…tab`, another TLD).
- If none of the five survives, a second round should use coined or compound names: the
  single calm words are taken.

## If the name changes — what else changes

- Store title and short name. Chrome's “Change back to Google?” bubble shows the extension
  name, so existing users will read the new one there.
- Icon (the yellow folder says “folders”), backup file prefix, upgrade summary text, landing page.
- Storage keys (`bos.*`) do not change.
