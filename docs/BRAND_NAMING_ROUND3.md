# Brand naming — round 3 (research only)

Date: 2026-10-02. Nothing was renamed, registered or bought. **Preliminary research, not legal trademark clearance.**

Method: 130 coined candidates → registry lookup (.com and three variants) and App Store search for every one → 30 shortlisted for GitHub, .app, Google Play and Chrome Web Store checks → web search for each survivor. Trademark registers (USPTO, EUIPO, TÜRKPATENT) were not searched directly.

Finding: every exact .com is registered, mostly by domain resellers, so the exact .com says nothing about use. The useful signals are the stores, GitHub and web search.

## Removed from round 2 (active software or product conflicts)

Diorama, Webstead, Anteroom, Kotona, Ibasho, Modara.
