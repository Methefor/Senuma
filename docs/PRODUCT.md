# Product

Senuma is the next version of New Tab Folders on the same store item. Spaces, Modes, universal search, Command Center, Continue, dock and personalization form the released product foundation.

The active 2.1 development line adds encrypted multi-device sync. Its rules, transport, sync engine and mock sign-in flow run against a local Firebase emulator; no production backend or real account service is connected. Senuma 2.0 remains packaged separately and has not been uploaded.

See ARCHITECTURE.md, CLOUD_SYNC_DESIGN.md, PRIVACY_FACTS.md and LEGACY_MIGRATION.md for verified implementation details.
