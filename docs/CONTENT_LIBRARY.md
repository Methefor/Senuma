# Short-form content library

Internal; nothing is posted. 22 launch-ready concepts. The calendar that schedules them is
LAUNCH_PLAN.md; wording comes from MESSAGING_SYSTEM.md; recording tools are in MEDIA_PLAN.md.

Rules for every clip:

- Real Senuma UI, recorded from the real build. No mock-ups, no fake numbers, no competitor names.
- Privacy claims only as allowed in MESSAGING_SYSTEM.md (“Privacy claims”): free, no Senuma
  account, no analytics, no Senuma cloud required in this release, workspace data stays local in
  this release. **Never show or imply zero network activity** (no Network-panel shots).
- 5–15 seconds, one idea, the point visible in the first 2 seconds, readable muted.
- Overlay text: at most two lines on screen at once, top or bottom safe area.
- CTA is always the same family: “Senuma — free on the Chrome Web Store” (TR: “Senuma — Chrome Web
  Store’da ücretsiz”). The link goes in the caption/bio with the channel's tag.
- Formats: 9:16 for Shorts/TikTok/Reels, 16:9 or GIF for X/Threads/Bluesky/GitHub/Reddit.

Each entry: **Hook** (first frame text) · **Storyboard** (seconds) · **Overlay** · **Caption** ·
**Channels** · Turkish versions of hook, overlay and caption.
