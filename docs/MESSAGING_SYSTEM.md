# Senuma messaging system (EN / TR)

The one source for product wording. Store listing (STORE_LISTING.md), screenshots, GIF captions
and video (MEDIA_PLAN.md), the user guide (guide/en.md, guide/tr.md) and the Help Center
(HELP_CENTER.md) take their lines from here. Change a line here first, then where it is used.

Rules for every line:

- Describe what Senuma does today. No feature that is not in the build, no numbers that were not measured.
- No “best”, “#1”, “fastest”, “boost your productivity by…”, no rankings, no testimonials.
- Senuma is a new-tab workspace, not “bookmark folders”. “Previously New Tab Folders” appears only where people upgrading need it.
- Product names are not translated: Senuma, Spaces → **Alanlar**, Modes → **Modlar**, Dock → **Dock**, Command center → **Komut merkezi** (the names the Turkish interface uses).
- The legal status of the name is open (SENUMA_BRAND.md). No copy says or implies it is registered or cleared.

## 2. Feature level

Each feature has a short headline (3–5 words), a one-sentence description, and a 2–3 sentence
description for landing and store use.
